# assets/brand — бренд-пакет сетки «ЧП [Город]»

Упаковка каналов трёх городов пилота (Магнитогорск, Новокузнецк, Череповец) и
генераторы визуала. Скрипты написаны так, чтобы уехать в конвейер: город и
категория — параметры, никаких хардкодов одного города.

## Что здесь

| Файл | Что |
|---|---|
| `NAMING.md` | по 3 варианта названия/описания/@юзернейма на канал ТГ и группу VK |
| `PINS.md` | тексты закрепов «прислать новость — платим», кнопка UGC, правила одной строкой |
| `DECISIONS.md` | что выбрано: названия, юзернеймы, стиль знака, тексты закрепов |
| `brand.py` | бренд-конфиг: палитра, города, категории, шрифты, текстовые примитивы |
| `avatars.py` | генератор аватарок: 2 стиля × 3 города × ТГ/VK + обложки VK |
| `covers.py` | генератор шаблонных обложек постов по категориям |
| `fonts/` | как ставятся шрифты (сами файлы в git не идут) |
| `out/` | сгенерированные PNG |

## Запуск

```bash
cd assets/brand
python3 avatars.py --all      # аватарки, обложки VK, контактные листы для выбора
python3 covers.py --all       # обложки постов по всем городам и категориям
```

Точечно:

```bash
python3 avatars.py --style a --city magnitogorsk --size 512 --out ava.png
python3 covers.py --city cherepovets --category fire --district "Зашекснинский район" \
    --title "Горит расселённый дом на Наседкина" --handle "@example_channel_1"
```

Выбран стиль A с буквенными кодами городов (`DECISIONS.md`). Контактные листы
`out/avatars/CONTACT-SHEET-*.png` сохранены как запись альтернатив: стиль B и
версии `-region` живут в генераторе (`--style b`, `--code-style region`), но
отдельными файлами не выкладываются.

## Система

**Палитра.** База — графит `#14171C`: чистый чёрный сливается с тёмной темой
Telegram, графит держит форму круга. Акцент у каждого города свой и максимально
разведён по тону, чтобы в списке чатов каналы сети различались цветом раньше,
чем прочитается код города: Магнитогорск — красный `#E63329`, Новокузнецк —
янтарь `#F5A623`, Череповец — синий `#2E86DE`.

**Читаемость знака.** Аватарка в списке чатов — кружок 40 px. Отсюда правила:
один доминирующий элемент, никаких тонких линий, кольцо по краю (иначе тёмный
круг растворяется в тёмной теме). Контактные листы показывают знак на 40/64/96 px
на светлой и тёмной теме — проверка, а не украшение.

**Две цветовые оси не спорят.** На обложке поста ведёт цвет категории, цвет
города уходит в маленький бейдж кода региона в шапке.

**Обложка адаптивная.** Есть заголовок — герой заголовок, категория уходит в
плашку-чип; заголовка нет — герой само название категории. Оба случая реальны:
второй нужен «молниям» и коротким сообщениям.

**Юзернеймы — в конфиге.** Выбранные адреса каналов лежат в `brand.py`
(`CITIES[*]["tg"]`, `["vk"]`, `UGC_BOT`) и подставляются в подпись обложки сами —
чтобы у publisher'а был один источник правды, а не строка в шаблоне.

**Никаких нейрокартинок.** Всё рисуется примитивами Pillow — это ступень 3
медиа-каскада из `docs/PROJECT-SPEC.md` §5, страховка на случай, когда чистого
медиа в кластере нет.

## Куда это уедет в конвейере

`covers.py:cover()` — прямой кандидат в шаг медиа-каскада (фаза 5, критерий
приёмки «драфт с чужим вотермарком не выходит в публикацию — вместо него
шаблонная обложка»). Сигнатура уже конвейерная: `cover(city_key, category,
district, title, handle)`. `brand.py` при этом остаётся единственным местом,
где живут цвета, шрифты и коды городов.
